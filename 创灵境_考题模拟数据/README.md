## 二、场景设定

### 企业背景

- **中药一厂**：产能较大，设备较新（2021-2023年投产），成本管理相对成熟
- **中药二厂**：产能较小，设备稍旧，部分药材自采有成本优势，但人工效率和设备利用率偏低
- 两厂同属某中成药集团，存在对标分析需求

### 三个产品

| 产品 | 剂型 | 规格 | 月均产量(一厂) | 单位成本区间 |
|------|------|------|-------------|------------|
| 银黄口服液 | 合剂 | 10ml×10支/盒 | ~50,000盒 | 10.5-11.2元/盒 |
| 板蓝根颗粒 | 颗粒剂 | 10g×20袋/盒 | ~90,000盒 | 7.0-7.5元/盒 |
| 六味地黄胶囊 | 胶囊剂 | 0.3g×60粒/盒 | ~35,000盒 | 17.0-18.1元/盒 |

### 6个月分析周期

| 月份 | 业务特征 | 成本波动特点 |
|------|---------|------------|
| 2026年1月 | 元旦假期影响，产量偏低 | 成本正常 |
| 2026年2月 | 春节假期，产量全年最低 | 固定费用摊薄不足，单位成本偏高 |
| 2026年3月 | 节后复产，产量恢复 | 成本回落 |
| 2026年4月 | 旺季开始 | 部分药材开始涨价 |
| 2026年5月 | 生产高峰 | 药材涨价高峰（金银花+12%，板蓝根+10%） |
| 2026年6月 | 生产正常 | 成本回落，改善措施见效 |

## 三、数据特征说明

### 3.1 成本波动设计意图

数据中有意设计了以下成本波动，供参赛团队验证归因分析能力：

| 波动事件 | 涉及产品 | 发生月份 | 根因 |
|---------|---------|---------|------|
| 金银花采购价上涨12% | 银黄口服液 | 4-5月 | 产地减产，市场行情上涨 |
| 板蓝根采购价上涨10% | 板蓝根颗粒 | 5月 | 流感季需求增加 |
| B药材(黄芩提取物)单耗上升 | 银黄口服液 | 4-6月 | 提取工艺收率波动 |
| 制造费用环比上升 | 全部产品 | 2月 | 春节期间固定费用摊薄不足 |
| 山茱萸价格上涨 | 六味地黄胶囊 | 4-5月 | 库存偏低 |
| 胶囊填充机故障 | 六味地黄胶囊 | 3月 | 设备维修导致停工24h |

### 3.2 对标差异设计意图

中药二厂与一厂的核心差异：

| 差异维度 | 一厂优势 | 二厂优势 | 典型差异率 |
|----------|---------|---------|-----------|
| 材料成本 | 规模采购价格略低 | 黄芩自采成本低 | 1-3% |
| 人工成本 | 设备新，效率高 | — | 二厂高10-15% |
| 制造费用 | 新设备折旧高 | 旧设备折旧低 | 二厂高5-8% |
| 单位成本 | 综合有优势 | 个别产品有亮点 | 二厂高2-5% |

### 3.3 预算与人工工时口径说明

**预算数据**（`中药一厂_预算数据_2026年.csv`）：预算为年度固定目标（标准成本口径），每月相同。1-3月实际成本接近预算，4-6月因药材涨价实际高于预算，预算偏差即为成本管控偏离度。

**人工工时明细**（`中药一厂_人工工时明细_2026年1-6月.csv`）：提供产量、直接人工总额、总工时、生产人数、工作天数 5 列，其余指标由参赛团队按下列公式派生：

```
单位人工成本(元/盒)   = 直接人工总额 ÷ 产量
人工工时(h/万盒)      = 总工时 ÷ 产量 × 10000
平均小时工资(元/h)    = 直接人工总额 ÷ 总工时   (含计件/加班因素)
人工效率(盒/人·日)    = 产量 ÷ (生产人数 × 工作天数)
```

> 说明：2月春节产量低，固定人工成本摊薄不足，单位人工成本偏高、人工效率偏低；5月生产高峰，效率提升但含加班因素小时工资上升。

## 四、使用指南

### 4.1 成本数据加载

所有CSV文件编码为UTF-8 BOM（兼容Excel直接打开），推荐在代码中使用pandas加载：

```python
import pandas as pd
df = pd.read_csv("01_成本明细数据/中药一厂_成本汇总_2026年1-6月.csv")
```

### 4.2 RAG知识库构建

推荐将 `03_制药知识文档/` 下的所有 `.pdf` 文件（先解析为文本）作为知识库文档导入向量数据库。

文档切分建议：
- **配方文档**: 按章节切分（产品信息/处方组成/功能主治/变更记录）
- **工艺文档**: 按工序切分（每个工序一个chunk）
- **设备清单**: 按车间切分（口服液车间/颗粒剂车间/胶囊剂车间）
- **GMP摘要**: 按章节切分（每章一个chunk）

检索策略建议：
- 混合检索：BM25（关键词）+ 向量检索（语义），权重建议 0.3:0.7
- 返回Top-5结果，标注来源文档和页码

### 4.3 报告模板使用

模板使用 `{{变量名}}` 语法标注动态数据占位符。参赛团队需实现模板解析引擎：

```python
# 模板变量示例
placeholders = {
    "{{产品名称}}": "银黄口服液",
    "{{本月单位成本}}": "11.21",
    "{{材料成本环比}}": "+5.3%",
    # ... 更多变量
}
```

### 4.4 RPA接口使用

```bash
# 启动模拟服务
cd 05_RPA接口文档/
pip install -r requirements.txt
python3 mock_rpa_server.py

# 验证
curl http://localhost:8090/health
```
